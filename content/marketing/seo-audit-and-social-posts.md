# Daily Utility Dock SEO audit and content distribution plan

Updated: 2026-06-02

## Audit summary

Daily Utility Dock already has a solid SEO base: category landing pages, tool pages with explanatory copy, FAQ schema, static blog routes, canonical metadata, and a generated sitemap. The main opportunity is to make the site feel less like separate utilities and more like a connected authority hub.

## Weakest pages and priority fixes

1. **Uncovered SEO tool pages**
   - Weakness: many high-intent tools had no supporting guide content.
   - Fix in this update: five new guides now support Budget Planner, Loan Repayment Calculator, UK Take-Home Pay Estimator, UK Energy Direct Debit Calculator, and JSON Formatter.

2. **Category pages without guide links**
   - Weakness: category hubs had strong tool links but did not surface related articles.
   - Fix in this update: category pages now show related guides based on the tools in each category.

3. **Tool pages without guide CTAs**
   - Weakness: tool pages did not send visitors to explanatory articles, so blog and tools were not bidirectionally linked.
   - Fix in this update: tool pages with matching articles now display a "Full guide" CTA.

4. **Navigation link equity**
   - Weakness: header and footer links under-represented category hubs and newer high-intent tools.
   - Fix in this update: header and footer links now surface more categories, finance tools, IT utilities, and selected guides.

5. **Sitemap and structured data quality**
   - Weakness: sitemap URLs used uniform daily frequency and priority, and WebSite schema referenced a search route that does not exist.
   - Fix in this update: sitemap generation now uses route-specific priority and change frequency with lastmod values; the invalid SearchAction was removed.
